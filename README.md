# 📊 investMaster – Planilha de Planejamento de Investimentos

Atividade prática de Excel desenvolvida durante o curso **[nome do curso]**, na plataforma **[nome da plataforma/instituição]**.

## 📌 Sobre a atividade

O **investMaster** é uma planilha que simula o crescimento de investimentos ao longo do tempo, ajudando a planejar aportes mensais e a distribuir o dinheiro entre diferentes tipos de ativos.

## 🧩 Estrutura da planilha

- **Configurações:** dados de base, como salário, rendimento e parâmetros usados nos cálculos.
- **Investimento Mensal:** valor aportado por mês, tempo de investimento e taxa de rendimento.
- **Cenários:** projeção do patrimônio acumulado em diferentes prazos (5, 10, 20 e 30 anos).
- **Distribuição dos investimentos:** percentual sugerido para cada tipo de ativo e o valor correspondente.
- **Gráfico:** visualização do percentual de cada categoria na distribuição.

## 🛠️ Recursos de Excel utilizados

- Fórmulas e cálculos financeiros
- Formatação condicional e formatação de células
- Gráficos
- Layout e identidade visual personalizados

- ## ▶️ Como usar

1. Baixe o arquivo `.xlsx` deste repositório.
2. Abra no Microsoft Excel (ou outro programa compatível).
3. Altere os valores das células de configuração para simular o seu cenário.
